# ADR 0070: Patch 083 correction, ABI-role query contract, and lifecycle continuity

## Status

Accepted as the Patch 084 implementation decision. Exact-source acceptance remains pending the documented native and container gates.

## Context

Patch 083 completed an outcome-blind natural-coordinate campaign but its review found a bounded set of acceptance defects outside the analyzer runtime:

- a generated ordered-pair binary was committed as source;
- the campaign's structural-completion option did not distinguish a fully accounted diagnostic result from comparison qualification;
- material campaign policy fields and source identity were not authenticated completely;
- a post-effect patch-path parent could be rebound before success verification;
- one corrupt recovery path closed a retained descriptor before rollback;
- the Docker build authenticated its self-derived tree without comparing it with the caller's expected candidate tree;
- authenticated `/work` source was owned by the non-root runtime user; and
- strict shell lint rejected an unused loop variable.

The natural campaign remains a valid diagnostic result even when no cell qualifies. That outcome must remain visible without being relabeled as either missing evidence or comparative success.

Sprint 13 also needs a stable private consumer contract for existing exact-pop role facts before it considers another runtime representation, public projection, or score change. The role contract must preserve the distinction between System V call argument four (`rcx`) and Linux syscall argument four (`r10`).

## Decision

Patch 084 makes no analyzer, include, schema, semantic, score, capacity, decoder, or worker change.

### Source and delivery correction

- Remove the generated ordered-pair binary from tracked source and ignore its generated path.
- Preserve one exact committed Patch 083 base for Patch 084 application.
- Require post-effect parent and leaf identity reauthentication before patch-transaction success.
- Keep corrupt recovery member descriptors open through identity-qualified rollback.
- Bind Git-less source and Docker context construction to an explicit expected candidate tree.
- Keep authenticated `/work` root-owned and verify dynamically that the runtime user cannot write it.
- Preserve ordinary writable build/test activity beneath the separate non-root run root.

### Natural-coordinate authority

- Validate the complete campaign, relation, selection, execution, qualification, terminal-state, and claim-boundary contract.
- Bind every retained run to an exact candidate tree and authenticated Git-less source-manifest digest.
- Keep structural completion separate from comparison qualification.
- Treat all nine cells as terminal diagnostic states even when none qualifies.
- Require nine qualified cells only for a comparison-qualification gate; do not make that a requirement for accepting the corrective product patch.

### Private ABI-role query contract

Freeze 36 named queries:

- 24 development queries;
- 12 source-disjoint confirmation queries;
- present, absent, and unknown answers;
- all 16 exact single-pop registers;
- generic non-`rsp` control;
- six System V argument positions;
- six Linux syscall argument positions;
- `rax` syscall-number and `rsp` pivot controls; and
- explicit `rcx`/`r10` cross-ABI negative cases.

The full local gate also runs 96 public command closures over 24 controlled ELF64 objects. Those closures must contain no private role projection.

### Lifecycle and denominator continuity

Preserve the last sealed lifecycle prefix:

```text
20 roots
30 leaves
29 aliases
2 folds
15 tombstones
161 lineage records
87 events
```

Patches 080 through 083 remain explicit unsealed deltas. No event 88, new canonical identity, tombstone reopening, or denominator reduction is authorized by Patch 084.

## Consequences

- The natural campaign may close structurally with zero qualified cells while still withholding all comparative claims.
- Public output remains schema `0.2.0` and exposes no role-query result.
- Existing role records remain the sole runtime representation; representation value and charged-memory cost remain separate experiments.
- Docker and full public-closure evidence remain local gates where the required tools are unavailable.
- Future work can use the frozen ABI query lattice without silently changing role semantics.

## Rejected alternatives

- Treating structural campaign accounting as comparison qualification.
- Rerolling natural targets after unfavorable or unavailable outcomes.
- Adding a public role field or non-null score from the query contract alone.
- Allocating another runtime tuple or role representation before equivalence and charged-memory evidence.
- Making a decoder or worker profile mandatory.
